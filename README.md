# Estudio Contable Tributario VCc

Sitio web informativo de VCc Asesoría Contable Tributaria, creado en un único archivo HTML con CSS y JavaScript incluidos.

## Publicar en GitHub

Abre una terminal en esta carpeta y ejecuta:

```bash
git init
git add index.html README.md
git commit -m "Publicar sitio web de VCc"
git branch -M main
git remote add origin https://github.com/Vane122710/Estudio-Contable-Tributario-VCc.git
git push -u origin main
```

Si el remoto `origin` ya existe, usa `git remote set-url origin https://github.com/Vane122710/Estudio-Contable-Tributario-VCc.git` en lugar de `git remote add origin ...`.

Después, en GitHub ve a **Settings → Pages**, selecciona **Deploy from a branch**, elige `main` y la carpeta `/(root)`, y guarda. La página se publicará en `https://vane122710.github.io/Estudio-Contable-Tributario-VCc/` cuando termine la compilación de Pages.

## Antes de publicar

Edita en `index.html` el teléfono de WhatsApp, correo, dirección, redes y testimonios de ejemplo. Revisa el endpoint del tipo de cambio y actualiza las fechas del cronograma tributario cada año con los datos oficiales de SUNAT.
